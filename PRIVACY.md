# AlgoLens Privacy Policy

**Last updated:** October 21, 2026

## Overview

AlgoLens is a browser extension designed to help users understand LeetCode solutions through step-by-step code tracing, variable inspection, execution highlighting, and data-structure visualizations.

## Data Collection

AlgoLens is designed to process code and page information locally within the browser. The extension does not intentionally collect or transmit personal information, LeetCode solutions, or browsing activity to its developer.

## Local Processing and Storage

AlgoLens accesses supported LeetCode problem pages to obtain the problem context and solution code needed for its functionality. Tracing and visualization are performed locally using the extension's packaged resources.

The extension may use browser extension storage for settings or other necessary state. Any stored information remains within the user's browser profile unless the implementation explicitly transmits it elsewhere.

## Third-Party Services

AlgoLens does not require a developer-operated backend or paid code-execution service for its core tracing functionality. This statement does not cover any third-party requests made by dependencies; such requests must be reviewed against the actual distributed build.

## Security

Users should avoid entering passwords, API keys, or other secrets into code they intend to trace. Users should keep their browser and extension updated.

## Changes to This Policy

This policy may be updated if AlgoLens's functionality or data practices change.
